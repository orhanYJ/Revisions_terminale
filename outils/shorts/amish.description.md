## Description
Comment un seul couple peut-il marquer les gènes de toute une communauté ? 🧬

XVIIIe siècle : quelques familles amish quittent l'Europe pour la Pennsylvanie. L'un des membres d'un couple porte, sans le savoir, un allèle muté très rare.
Un seul exemplaire : aucun symptôme. L'allèle passe de génération en génération… jusqu'au jour où deux porteurs ont un enfant ensemble.
Le syndrome d'Ellis-van Creveld (très petite taille, souvent un sixième doigt) touche à peine 1 naissance sur 60 000 ailleurs dans le monde. Chez les Amish de Pennsylvanie, l'allèle atteint 7 % : toutes les familles touchées descendent du même couple.
Ce n'est pas un mystère : c'est l'effet fondateur, puis la dérive génétique.
