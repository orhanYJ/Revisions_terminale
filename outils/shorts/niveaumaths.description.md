## Sources (pour répondre aux commentaires)
Programme de spécialité mathématiques de Terminale générale (BO spécial n° 8 du 25 juillet 2019, eduscol). Résultats recalculés :
- u(0) = 3 et u(n+1) = 2 u(n) : u(1) = 6, u(2) = 12 (suite géométrique de raison 2) ;
- si f″ ≥ 0 sur un intervalle, f est convexe sur cet intervalle : sa courbe est au-dessus de ses tangentes ;
- (2n + 1) / (n + 3) = (2 + 1/n) / (1 + 3/n), qui tend vers 2 quand n tend vers + l'infini ;
- ln(8) = ln(2³) = 3 ln(2), donc k = 3 ;
- une primitive de 2x est x² : l'intégrale de 0 à 1 de 2x vaut 1² − 0² = 1 (l'aire du triangle de base 1 et de hauteur 2) ;
- 5 personnes : une poignée de main par paire, « 2 parmi 5 » = (5 × 4) / 2 = 10 ;
- deux dés équilibrés : P(aucun 6) = (5/6)² = 25/36, donc P(au moins un 6) = 1 − 25/36 = 11/36 (environ 0,31).
- À l'écran : Napier publie les logarithmes en 1614 ; Leibniz écrit le signe de l'intégrale pour la première fois en 1675 ; la planche de Galton illustre la loi binomiale.
