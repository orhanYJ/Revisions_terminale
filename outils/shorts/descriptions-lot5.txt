## Sources (pour répondre aux commentaires)
- Internet est le réseau ; le Web est un service qui l'utilise, proposé par Tim Berners-Lee au CERN en mars 1989 ; le courrier électronique passe par Internet sans passer par le Web (CERN, « A short history of the Web »).
- Une adresse IPv4 fait 4 octets, soit 32 bits (RFC 791, 1981) : 2 puissance 32 = 4 294 967 296 adresses. IPv6 (128 bits) a été créé parce qu'il n'y en a pas assez.
- Le 9 septembre 1947, l'équipe du calculateur Harvard Mark II trouve une mite dans le relais n° 70 et la colle dans son journal avec la mention « First actual case of bug being found » : « premier cas réel », car le mot existait déjà (Smithsonian, National Museum of American History ; Computer History Museum). Thomas Edison employait déjà « bug » pour un défaut technique dans ses lettres de 1878 (IEEE Spectrum).
- Ada Lovelace publie en 1843, dans ses notes sur la machine analytique de Charles Babbage (Note G), un algorithme pour calculer les nombres de Bernoulli, considéré comme le premier programme publié ; la machine n'a jamais été construite (Scientific American).
- Le problème de l'arrêt est indécidable : aucun programme ne peut dire, pour tout programme, s'il finira par s'arrêter, quel que soit le temps dont il dispose (programme de NSI de Terminale ; Alan Turing, « On Computable Numbers », 1936).

## Sources (pour répondre aux commentaires)
Programme officiel de la spécialité NSI de Terminale (Bulletin officiel spécial n° 8 du 25 juillet 2019, eduscol) ; chaque résultat a été vérifié en exécutant le code en Python.
- 13 = 8 + 4 + 0 + 1 = 1101 en binaire (bin(13) donne '0b1101').
- Une pile suit la règle « dernier entré, premier sorti » (LIFO) : on empile A, B, C, on dépile C. Une file suit « premier entré, premier sorti » (FIFO) : A sort en premier.
- SQL : SELECT … FROM … WHERE condition ; WHERE ne garde que les lignes qui vérifient la condition.
- def f(n): si n == 0, renvoyer 0 ; sinon renvoyer n + f(n - 1). f(4) = 4 + 3 + 2 + 1 + 0 = 10.
- Recherche dichotomique : on coupe la zone de recherche en deux à chaque étape ; pour 1 000 000 d'éléments triés, 20 étapes au plus (2 puissance 20 = 1 048 576).
- Le problème de l'arrêt est indécidable : aucun programme ne peut dire, pour tout programme et toute entrée, s'il finira par s'arrêter. L'idée remonte à l'article d'Alan Turing « On Computable Numbers » (1936), qui montre les premiers problèmes indécidables (Stanford Encyclopedia of Philosophy, « Turing Machines »).

## Sources (pour répondre aux commentaires)
Programme de spécialité mathématiques de Terminale générale (BO spécial n° 8 du 25 juillet 2019, eduscol). Résultats recalculés :
- u(0) = 3 et u(n+1) = 2 u(n) : u(1) = 6, u(2) = 12 (suite géométrique de raison 2) ;
- si f″ ≥ 0 sur un intervalle, f est convexe sur cet intervalle : sa courbe est au-dessus de ses tangentes ;
- (2n + 1) / (n + 3) = (2 + 1/n) / (1 + 3/n), qui tend vers 2 quand n tend vers + l'infini ;
- ln(8) = ln(2³) = 3 ln(2), donc k = 3 ;
- une primitive de 2x est x² : l'intégrale de 0 à 1 de 2x vaut 1² − 0² = 1 (l'aire du triangle de base 1 et de hauteur 2) ;
- 5 personnes : une poignée de main par paire, « 2 parmi 5 » = (5 × 4) / 2 = 10 ;
- deux dés équilibrés : P(aucun 6) = (5/6)² = 25/36, donc P(au moins un 6) = 1 − 25/36 = 11/36 (environ 0,31).
- À l'écran : Napier publie les logarithmes en 1614 ; Leibniz écrit le signe de l'intégrale pour la première fois en 1675 ; la planche de Galton illustre la loi binomiale.

## Sources (pour répondre aux commentaires)
Programme de spécialité mathématiques de Terminale générale (BO spécial n° 8 du 25 juillet 2019, eduscol). Chaque ligne a été vérifiée :
- Logarithmes : ln(ab) = ln(a) + ln(b), mais il n'y a pas de règle pour ln(a + b). ln(3 + 4) = ln(7) (environ 1,95), alors que ln(3) + ln(4) = ln(12) (environ 2,48). Les autres lignes sont justes : ln(1) = 0, ln(2 × 5) = ln(2) + ln(5), ln(e²) = 2.
- Exponentielle : la dérivée de exp(u) est u′ × exp(u). Pour f(x) = exp(2x) : f′(x) = 2 exp(2x), et non exp(2x). Les autres lignes sont justes : exp(2x) > 0, f′(x) > 0 donc f croissante, f(0) = 1.
- Limites : en + l'infini, x² − x donne « + l'infini − l'infini », une forme indéterminée, pas 0. On factorise : x² − x = x(x − 1), produit de deux facteurs qui tendent vers + l'infini, donc la limite est + l'infini.
- À l'écran : Napier publie les logarithmes en 1614 ; e est appelé « nombre d'Euler ».
